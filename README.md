Plant Disease AI 🌱

About the Project

Plant Disease AI is a machine learning project designed to identify plant diseases from leaf images using Artificial Intelligence.

Objectives

- Detect plant diseases from leaf images.
- Help identify unhealthy plants.
- Support early disease detection.

Technologies Used

- Python
- Machine Learning / Deep Learning
- TensorFlow or Keras
- OpenCV
- Streamlit (for the user interface)

Project Status

Currently under development.
